MEU TREINO DE QUESTÕES — PWA V2

Novidade: backup e restauração.

Para criar backup:
1. Abra Desempenho.
2. Toque em Exportar backup.
3. Guarde o arquivo JSON.

Para restaurar:
1. Abra Desempenho.
2. Toque em Importar backup.
3. Escolha o arquivo JSON exportado pelo aplicativo.
4. Confirme a substituição dos dados locais.

O backup inclui as questões cadastradas por você e o histórico de respostas. As questões que já vêm com o aplicativo continuam no próprio app.
